How Industry Standards Handle 100+ Permutations

🎯 1. Score Multiplier / Heat System

Used by: Hades (Pact of Punishment), Brotato, Slay the Spire.

Instead of 100 separate leaderboards with 1 player each, there is ONE central leaderboard per game. Harder modifiers multiply the score!

  • Zero Clutter: 4 games = 4 clean leaderboards total.
  • Zero Spoilers: Players never see a list of variants until The Card flips.
  • Maximum Rivalry: Everyone competes on the same board.

📖 2. Split Leaderboard vs Codex

Used by: Balatro, Super Smash Bros, Pokemon.

Separate the Competitor from the Collector:

  • Leaderboard: Kept strictly for standard competitive baseline play.
  • The Codex (in Profile): Houses all 100+ variants as discoverable mystery entries (??? until encountered).
  • Preserves suspense and satisfies completionists without wrecking the UI.

🧭 3. Orthogonal 3-Axis Facets

Used by: TrackMania, Speedrun.com, Steam Workshop.

Never treat 100+ variants as a 1D flat list. Break the 9 Memory dimensions down into 3 independent orthogonal dials:

  • Axis 1 (Board Size): 6, 8, 10, 16 pairs.
  • Axis 2 (Mode): Standard, Rush Timer, Survival.
  • Axis 3 (Modifier Class): Clean, Moving Cards, Trios.

⚡ 4. 24-Hour Daily Mutation

Used by: Spelunky Daily, Wordle, Slay the Spire Daily Climb.

Keep 1 permanent Classic board. The other 100+ modifiers are served exclusively through the Daily Mystery Challenge.

  • Each day, the server HMAC-seeds a surprise combo.
  • Today: Trios + Moving Cards. Tomorrow: No Preview + 16 Pairs.
  • Concentrates all players onto one exciting event daily.
