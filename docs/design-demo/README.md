# design-demo

Reference exports of the owner's UI demo canvas (home, memory, block puzzle, result, desktop, theme variety, font candidates, and generated themes). **Reference only.** Some hex values here predate the contrast and color-blind audit, so the tokens in `docs/PLAN.md` section 11.1a win. The `.dc.html` files need the canvas host to render; the live canvas is at https://claude.ai/artifact/EpykFsRWG1XD7i6DryzJ9w (private to the owner).

These files are excluded from search by `.ignore` to save tokens. Open them by path when you need a visual reference.

**Owner task before Phase 0:** export static PNG screenshots of every board (with their sizes) into `docs/design-demo/screens/`, so the design reference does not depend on the private canvas.

Note: the Home board shows the first single-button Home. The landing page described in `docs/PLAN.md` section 11.1 (no-scroll, three columns on wide screens) supersedes it, and the puzzle page template (section 11.16) supersedes the single centered stage in the other boards.
