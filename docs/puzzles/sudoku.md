# Sudoku

Fill the 9×9 board with digits 1–9. Rows, columns and regions each hold every digit
once. Tap a cell and then a digit. Conflicts leave the cell unchanged. Other
incorrect placements count toward the configured mistake limit.

Sudoku ships enabled with Classic and ten enabled presets. Presets change the
rules, available information, or the time limit. Generated board grades
describe the hardest technique used and are independent of player progression.
Every board is unique and logic-solvable. The daily seed must also grade Easy.

The existing daily board key is `(sudoku, UTC date)`. Sudoku adds zero variant
leaderboard groups. Wins and losses consume the ranked daily attempt. A loss
scores zero. A zero-point win can still appear on the board if it clears the
timing and hint ranking gates.

## Operator settings

`brief-v1` sets the family defaults. Changes create immutable versions. A daily
board and sessions issued for it use the version pinned to that board. The next
unpinned board picks up the current version.
