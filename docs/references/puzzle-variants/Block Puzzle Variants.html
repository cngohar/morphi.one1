Block Puzzle Variants

A catalogue of named, published block-placement games and modes that change a rule compared with Morphi's Block base — an 8×8 board, a three-piece tray, rows and columns clearing together, combo scoring, and a no-fit ending. 29 entries are listed: 22 verified and 7 flagged. Collapsing same-dimension duplicates leaves 16 distinct rule systems. Research only — no variant pick or build is made here.

The base every variant is measured against

The comparison base is Morphi's Block game as stipulated for this research. Entry 0 in the research — Block Blast! Classic and the generic 8×8 “Block Puzzle” — matches it almost exactly, so it is treated as the base itself, not counted as a variant.

The base game

  • 8×8 board; drag polyomino pieces from a three-piece tray onto the board.
  • A full row or a full column clears; rows and columns can clear together.
  • Clearing multiple lines at once gives a combo bonus.
  • Pieces have a fixed orientation — no rotation, no flipping.
  • The round ends when no tray piece fits anywhere (no-fit), with a move cap.

The 8×8 base board mid-round, a full row about to clear, and the three-piece tray.

Base discrepancy, flagged by the research: the published Blockudoku is 9×9 with rows, columns and 3×3 squares clearing — not this 8×8 rows-and-columns base. The stipulated base instead matches published Block Blast! Classic (8×8, 3 pieces, rows+columns, no rotation) almost exactly.

Move-cap ambiguity: published Classic games are described as endless / no-fit with no move cap. If a move cap is part of the base, move-limited levels (entries 4 and 9) are parameter changes rather than new endings, and the core count would fall by at most 1 system. The full count of 29 does not change.

Counting convention

A named published mode or game is counted once, and only if it changes a rule versus the base — never for a new theme, colour, artwork, board skin, sound, or a mere scoring-value change. Same-dimension duplicates stay in the full list of 29 but are collapsed in the core count of 16. Classifications marked inference are the researcher's judgement, not published facts. Evidence is web-index unless a page was opened; no live in-app verification was possible (signed-out research only).

The catalogue — 29 named variants

Each entry states its exact rule change versus the base, its evidence status, and whether it is data-only (same placement and clear mechanics, different parameters) or needs new mechanics (a new rule such as rotation, gravity, colour matching, or special pieces). Flagged entries are excluded from the core count of 16.

Rule dimensions — what actually varies

Twelve dimensions were checked across the catalogue. These are the values the research actually found — including the dimensions where nothing verified exists, which matter as much as the ones that do.

Board size & shape
8×8 (base / Block Blast) · 10×10 (1010!, TenTrix) · 9×9 (Blockudoku, Woodoku, Poweroku) · 9×12 rectangular (Blockwood) · 10×20 tall (Reverse Blocks) · hexagonal, 6 large triangles (Woody Trigon) · circular rings+spokes / slices+rings (Prism Blast 3D, Wheel Block). No verified square board other than 8×8 / 9×9 / 10×10, and no verified board with pre-placed holes as a standalone rule — holes and obstacles appear as pieces (ice, stone, junk, chocolate), not fixed board holes.
Tray size & feed
3 pieces, refill only when empty — universal in verified games. Deviations: Block Sudoku's Holder (3 + 1 held piece); Reverse Blocks' timed feed into Storage, where overflow ends the run. No verified 1-, 2-, 4- or 5-piece standard tray found.
Piece set
Polyominoes (squares, bars, L/T/S shapes, the 3×3 square, the 1×5 bar as a run-killer on 10×10) · triangular pieces (Woody Trigon) · diagonal-shaped pieces mentioned in Color Block Adventure — unverified whether diagonal pieces or diagonal clears · unspecified “new blocks” in Plus Mode (flagged) · bending circular pieces (Wheel Block). No verified published piece-set catalogue distinct enough to count beyond these.
Rotation & flipping
Fixed orientation in the base, 1010!, TenTrix, Block Blast and Blockudoku (one source claims Blockudoku rotation — see uncertainties). Rotatable: Poweroku (free rotation), Reverse Blocks (tap to rotate), Block Sudoku Rotators (consumable), Woody Trigon rotate-or-delete tools. No verified flipping (mirror) rule found — rotation only.
Clear rules
Rows+columns (base) · rows only (Blocks Puzzle) · rows+columns+3×3 squares (Blockudoku / Woodoku) · 3+ connected same-colour (1010! Color) · same-colour full row (Sand Blast) · large-triangle fill (Woody Trigon) · slice / ring fill (Wheel Block) · ring / spoke fill (Prism Blast 3D) · exact cover, no clear (Jigsaw) · diagonal clears — unverified, unofficial web mode only (entry 28).
Scoring & combo
Placement points + per-cell line points (Block Blast web: 1/cell placed, 10/cell cleared) · simultaneous multi-line bonus in all games · consecutive-turn streak multiplier (Blockudoku / Woodoku, Block Blast guides) · all-clear bonus (Block Blast web: 360 pts for emptying the board) · squared multi-line score (Blockwood). Streak vs combo wording varies by source for the same games — treated as parameter / wording, not separate variants.
Timer, move limit & lives
No timer in the base / Classic. Fixed countdown: 15:00 (Blocks Puzzle), 60 s Rush (Sova). Replenishing: 90 s + time per line (Blockwood, Color Block Time Attack). Timed feed: Reverse Blocks Storage overflow. Move limit: Blockwood levels; Block Blast Adventure descriptions state one in some sources, not all (conflict — see uncertainties). Lives: one-use revive only (flagged, entry 29). No verified 3-lives system in a placement game found.
Level, mission & target modes
Endless high-score (base) vs level-target (Block Blast Adventure, Color Block Adventure, Sova Arcade, Blockwood levels) · collection targets — gems / stars / hearts (entry 6) · daily fixed puzzles (Blockudoku Daily, Block Blast Daily, PolySlide Daily) · tournaments / leaderboards (Blockudoku, asynchronous only).
Endings
No-fit (base, universal) · timer expiry (entries 7, 8, 10) · Storage overflow (entry 14) · level-goal completion / failure (entries 4, 6, 7, 9) · exact-cover completion (entry 23) · board-full with no room — the same as no-fit in TenTrix's wording.
Gravity & shifting after clears
None in the base — pieces stay where placed, explicitly stated for Block Blast. Fall-after-clear with chains (Gravity Tiles, TetroBlocks) · per-column slide on drop (Gravity Rise) · sand-grain settle (Sand Blast) · ring twist (Wheel Block — board rotation, not gravity). No verified “rows drop down after a line clear” in a non-gravity placement game beyond these.
Wild & special pieces
Bomb clearing 3×3 (Blockwood, Gravity Rise Item mode) · rainbow single-cell wild (Blockwood) · ice needing 2 clears (Blockwood) · stone / magma / rifts (Gravity Tiles) · grey junk (Prism Blast 3D) · chocolate / gumballs / gems (Wheel Block). Line blasters, area bombs and rainbow blocks claimed for Block Blast in SEO guides were not relied on — they conflate it with match-3 games. Colour-bomb / line-blast creation rules (match-4/5) belong to match-3, not verified placement rules.
Multiplayer & versus
No verified real-time versus placement game found. Blockudoku tournaments are asynchronous leaderboard competition; TenTrix sources explicitly say solo / no multiplayer, score-challenge only. Versus exists only in boundary families (Tetris / Dr Mario versus).

Boundary games — similar-looking, different family

These look like block puzzles but are not variants of the placement base, and are not counted.

Tetris & falling-block games (incl. Columns)Pieces fall on a timer and the game ends when the stack tops out; placement is not free drag-to-any-cell and there is no tray / no-fit ending.
Dr. MarioFalling two-colour capsules matched 4-in-a-line by colour with gravity chains — colour-matching of falling pieces, not tray placement.
Candy Crush Saga / Bejeweled (match-3)The board is pre-filled and the move is swapping adjacent tiles to make 3+ in a line, with gravity refill; no tray pieces are placed and no line is completed by filling a row.
Unblock Me / Klotski / Rush Hour (sliding-block)Blocks already on the board slide along their axis to free an exit piece; nothing is placed from a tray and nothing clears by completing a line.
2048 / Threes! (sliding merge)One swipe moves the whole board and equal tiles merge; the goal is a target tile, not line completion by placement.
15-puzzle / SokobanA fixed set of tiles or boxes is slid or pushed to a target arrangement; no new pieces, no clears.
1010 nine-modes — Pop Mode (entry 27)Tap-to-crush pre-placed same-colour groups; listed as flagged / boundary-adjacent because the placement loop is absent.
Classic tangram / jigsawA close cousin of entry 23, but with a fixed piece set and no random tray; entry 23 counts only because its games reuse the tray-placement loop with a fill goal.

Uncertainties, gaps & what was not counted

Open questions

  • Blockudoku rotation / diagonal conflict: official-description sources say no rotation and rows/columns/squares only; one low-quality PDF summary claims blocks can be rotated and diagonal lines clear. The official line is followed; rotation and diagonals for Blockudoku itself are unverified and conflicting.
  • Block Blast Adventure specifics conflict: some descriptions say target score / clear-N-blocks, others add move or time limits, and several SEO guides conflate it with match-3 bomb/rainbow creation. Only “level objectives exist” is treated as verified; per-level mechanics are not.
  • Possible clones / re-skins of one system: Woodoku vs Blockudoku (same 9×9 + square system, different publisher and theme); 1010! vs TenTrix vs generic 10×10; Woody Trigon vs Woody Poly (possibly same publisher lineage); “Block Puzzle / Block Sudoku / Wood Block Puzzle” store titles reuse each other's descriptions verbatim — several may be the same game under different listings.
  • Sparse modes: the 1010 nine-modes Bomb, Plus, Hexa and Slide are one-line store listings with no rule detail; only Slide is corroborated by an independent game (PolySlide), Hexa only by analogy to Woody Trigon.
  • Dimensions with no verified published value: real-time versus / multiplayer placement; tray sizes other than 3 (+hold); piece flipping / mirroring; fixed board holes as a starting layout (obstacles found only as pieces / junk); 3-lives systems; diagonal clears in a first-party published game.
  • Evidence quality: most entries rest on store descriptions or secondary guides, not first-party rulebooks or hands-on play; store listings are marketing copy and may describe planned or version-specific features. No source systematically enumerates modes for any single title.

Not counted, and why

  • Theme / skin clones: 1010! Fish Blocks, Jewel Blocks Quest, Wolfoo Block Blast, Luma Blocks and dozens of “wood / jewel / neon” reskins use the base rules with different art — excluded by the counting convention.
  • Pure scoring-value differences: e.g. Block Blast's 10 pts/cell vs 1010!'s line tables, or combo vs streak wording — parameters, not rule systems; recorded in the dimensions section, not counted.
  • Boosters alone: hammer, undo, refresh, or a bomb as a paid item in otherwise-base games — not standalone variants, unless the game or mode is built around them (entries 9, 15, 17, 18).
  • Match-3 conflation: SEO / guide claims that Block Blast's Adventure mode involves “matching 4–5 same-colour blocks to earn bombs / rainbow blocks” mix Block Blast up with match-3 games. Those descriptions were not relied on; the Adventure entry rests on level-objective descriptions only.
