  behavior and AdminTestPlay cancellation/unmount. No client permission bypass.

  no equivalent view restriction: do not silently add one.**

  disable retains validated reason/confirmation. Keep duration/deletion/restore
  rules, atomic service audit writes and cache invalidation. Helpers must not
  add duplicate read audit or mutate before authorization.
- Preserve serialized loader keys/defaults and unavailable fallback. Status
  exceptions rethrow; unexpected reads retain `morphi:operator_read_failed`.
  Preserve action redirects, RunError status/code, unexpected-error
  503/unavailable mapping and `morphi:operator_action_failed`.
- No data migration or change to old runs/checkpoints/sessions/scoring versions.
  Issued rounds and saved history keep their rules. Test play still writes no
  player sessions/completions/activity. Failures cannot expose server context or
  silently report success.
