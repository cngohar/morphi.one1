## 3. Server Replay, Determinism, and Cloudflare Integrity

1. **Integer-Only Determinism:**
   - All deck configurations, entangled pairs, firewall placements, anycast shifts, bit-rot order, and burst pings use deterministic integer PRNG (`createRng(seed)`).
   - Zero client-only floating point arithmetic.
2. **Authoritative Cloudflare / D1 Replay:**
   - Moves replay identically on Cloudflare Workers / workerd.
   - For `register-buffer`: server maintains the 1-slot buffer state across moves.
   - For `tls-handshake`: server verifies that triad moves match valid cryptographic cipher suites.
   - For `anycast-route`: server replicates exact clockwise perimeter indexing shifts.
3. **Loss / Penalty Handling (Ponytail / Cloudflare best practice):**
   - Rounds with rate-limit lockouts or trace quarantine record deterministic penalties without corrupting D1 session state.
   - No speculative storage tables or schemas required; existing `game_config` and `runs` tables handle all 10 variants natively.
