## 1. Scope, Purpose, and Catalogue Count

### Goal

Deliver **v1.3.5.12 — Batch E**, introducing **Morphi's first Split Dual-Garden Baseline (`memory:cross-pollination`)** and **10 genuinely new botanical & nature rulesets** (Cross-Pollination, Mycelium Root Pulses, Photosynthesis Cycles, Seed Dispersal Drift, Seasonal Wilt, Bee Waggle Vectors, Carnivorous Briars, Chlorophyll Sap Budget, Bioluminescent Spores, and Orchard Hybrid Grafting), expanding the playable Memory catalogue from **50 to 60 total variants** (and 150 to 180 leaderboard groups).

### Variant Definition Rule (Constraint C2)

Every variant introduces a **concrete, functional gameplay ruleset change** altering matching relations, turn structures, time/survival constraints, or board physics. In accordance with Constraint C2:

> _A changed board size or layout qualifies as a baseline and variant because the split dual-garden geometry fundamentally alters the core matching ruleset: cards can only pair across garden boundaries (1 Flower in the Meadow Pod + 1 Pollinator/Blossom in the Grove Pod)._

## 3. Server Replay, Determinism, and Integrity

1. **Integer-Only Determinism:**
   - All pod partitions, flower layouts, wind drift seeds, sunbeam rotations, and sap balances use deterministic integer PRNG (`createRng(seed)`).
   - Zero client-only floating point RNG.
2. **Authoritative Replay:**
   - Server re-executes the move sequence against the seed.
   - Cross-pollination rule verified server-side: moves within the same garden pod without cross-boundary resolution are rejected as invalid transitions.
   - For `chlorophyll-meter`: server validates `sap > 0` after every flip.
3. **Loss State Handling (Ponytail best practice):**
   - Rounds ending in loss (drought wilt in chlorophyll meter) do not corrupt session state or leaderboard entries.
   - Standard integer bounds and existing database tables handle all 10 variants natively without new database migrations.
