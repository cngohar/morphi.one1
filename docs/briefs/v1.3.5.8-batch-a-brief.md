## 3. Server Replay, Determinism, and Integrity

1. **Integer-Only Determinism:**
   - All deck layouts, wild card placement, hazard cards, drift shifts, and decay relocations are driven by the issued round seed (`createRng(seed)`).
   - Zero cosmetic RNG in game logic.
2. **Authoritative Server Replay:**
   - Server re-executes the move sequence against the seed.
   - For `countdown`: server checks `elapsedMs <= limitMs`.
   - For `three-strikes`: server validates `strikes < 3`.
   - For `wild-card`: server recognizes the wild pairing rule.
   - Client never submits score or validates win/loss.
3. **Loss State Handling (Ponytail / Cloudflare best practice):**
   - Rounds ending in loss (Countdown timeout, Three Strikes exhaustion) do not record leaderboard rows or score completions.
   - The failed board remains viewable with Try Another / Home actions.
   - Ranked sessions are cleanly marked abandoned by exact session ID without corrupting player stats.
