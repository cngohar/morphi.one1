## Actual identity path and smallest missing link

- Existing manifest and `puzzleVariant()` already fix the four codes and resolve omitted classic without rewriting its wire shape. `play_session` writes `(family,variant,seed,engine_version,score_config_version)` at issuance; `resumableRanked` returns the issued scoring snapshot; `saveRun` validates the version/variant, checks ranked issuance, fetches immutable score versions from D1/KV and replays moves on the server. `RoundCheckpoint` stores the same tuple plus local moves and full cosmetic theme. `CompletedRun` preserves variant/version/score-version (legacy omitted classic remains omitted). Existing DB/score schema and `memory-1`, `brief-v1`, `memory-trios-v1` suffice; do **not** add a second identity store or bump the manifest engine version.
- **Gap:** `PlaySession.restoreChoice()` accepts a same-ID local ranked checkpoint over the authoritative active session without comparing seed, variant, engine version or issued score snapshot. `resumeRound()` rereads the local checkpoint after taking ownership but only checks the active _ID_, so a stale/malformed same-ID checkpoint can replay the wrong variant or score while the server still owns a different issuance. Check exact issued tuple at both selection and resume after the lease refresh. Omitted/explicit classic must compare as one canonical variant. A mismatch discards only that _checkpoint choice_ and resumes the original issued round afresh (no unsanctioned server write or phantom score); retain the record until normal checkpoint replacement/explicit abandonment. Log a coarse recovery warning. Do not accept arbitrary score coefficients under a genuine version; compare normalized score fields to the issued snapshot. A ranked session may already have been disabled for new issuance: that does not invalidate its originally issued identity.
- **Unknown identity:** `resumableRanked` currently guards engine-version mismatch but a stored unknown variant or unreadable score version can throw while loading the active session. Return the existing non-resumable active-session conflict (id/expiry/saving) with a coarse warning; never substitute live defaults or a new seed. Client may take over or explicitly abandon using existing controls. Preserve a claimed/saving retry and original score history. Malformed checkpoint score-version shape/unknown family must fail safely; do not introduce an online dependency for solo offline resume. Future new IDs are outside .4.
