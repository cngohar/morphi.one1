## 1. Scope, Purpose, and Catalogue Count

### Goal

Deliver **v1.3.5.11 — Batch D**, introducing **10 genuinely new gameplay rulesets** inspired by Cloudflare's core distributed cloud platform technologies and edge architecture (Workers KV, Durable Objects, Vectorize, Cloudflare Queues, Workers AI, Hyperdrive, Turnstile, Zero Trust, Argo Smart Routing, and Cloudflare R2), expanding the playable Memory catalogue from **40 to 50 total variants** (and 120 to 150 leaderboard groups).

### Variant Definition Rule

Every variant introduces a **concrete, functional gameplay ruleset change** altering matching relations, turn structures, time/survival constraints, or board physics. No cosmetic relabeling, colors, or duplicate flag toggles count as variants.

## 3. Server Replay, Determinism, and Cloudflare Integrity

1. **Integer-Only Determinism:**
   - All deck layouts, actor row partitions, vector cluster distributions, queue batches, token burns, and glacier cycles use deterministic integer PRNG (`createRng(seed)`).
   - Zero client-only floating point RNG.
2. **Authoritative Cloudflare / D1 Replay:**
   - Server re-executes the move sequence against the seed.
   - For `ai-tokens`: server tracks `tokens > 0` after every move.
   - For `durable-object`: server validates that pair flips span separate actor rows.
   - For `zero-trust`: server enforces tier clearance order (Tier 1 cleared before Tier 2 flips).
   - For `vectorize-knn`: server verifies cluster membership parity.
3. **Loss State Handling (Ponytail / Cloudflare best practice):**
   - Rounds ending in loss (`ai-tokens` context overflow) do not corrupt D1 session state or record fraudulent leaderboard entries.
   - Standard integer bounds and existing database tables handle all 10 variants natively without new database migrations.
