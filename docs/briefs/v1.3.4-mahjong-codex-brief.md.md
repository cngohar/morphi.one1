All three: 100 points per pair, 1,000 clear bonus (starting values, admin-editable). Ranked entrance time follows the variant, not the family. Help text is variant-aware: Quick’s help does not mention Flowers and Seasons.

**Leaderboard groups** (follow Memory’s existing group-name pattern in code, including its version segment): `mahjong-solitaire-1:turtle`, `mahjong-solitaire-1:quick`, `mahjong-solitaire-1:fortress`. Scores are never mixed across variants.

**Selection:** family first, then a weighted variant draw avoiding the last variant served. Starting weights Quick 3, Turtle 1, Fortress 1, stored wherever v1.3 stores variant weights. Turtle and Fortress rounds run about ten minutes, so they stay rare.

## Rules

- Select two currently free tiles with matching faces to remove them. A tile is free when no tile covers any part of it and at least one long side has no same-level neighbour. Use integer half-step coordinates so overlap and neighbour tests are exact (the Turtle’s head and tail tiles straddle two rows).
- Exact face match, except any Flower matches any Flower and any Season matches any Season. Quick has no bonus tiles.
- Clear the board to win. If tiles remain and no legal free pair exists, the round ends as **blocked**.
- Selecting a non-matching free tile moves the selection with no penalty; selecting the same tile again cancels. Selection is client-only.
- The replay records successful removals only, as ordered pairs of tile ids. Maximum moves equals the pair count.
- The HUD shows tiles remaining and elapsed time. **No free-pair count** (it would be a hint). Free tiles are shown bright and blocked tiles dimmed; that is a state display, not a hint. Dead-end detection is immediate and shows a clear no-moves ending.

## Generation and fairness

- Deterministic from seed, variant and engine version. Integer-only in engine core, SplitMix64 streams as per the contract, separate cosmetic stream.
- Reverse-deal: repeatedly pick two positions that are simultaneously free, remove them from the working layout, and record the pair as the witness. Assign faces by shuffling the face-pair list with the unbiased shuffle and mapping it onto witness pairs, so top tiles are not systematically the same faces.
- Validate the witness before issuance. No runtime solver in the normal path. Generation must be bounded; define the timeout and the fallback.
- The witness is a test and validation artifact. It is never persisted in a session or checkpoint and never sent to the client.
- Layout coordinates are frozen data. Any change after release bumps the family `engine_version`.

## Eligibility (stage fit)

- A variant is drawn only if the stage can show its layout with every tile’s hit area at least 44 × 44 CSS px. In practice Quick qualifies on phones in portrait; Turtle and Fortress need tablet or desktop sizes. If no variant is eligible, the family is skipped for that draw. Nothing is announced to the player.
- Eligibility is decided selector-side. Layout, generation and replay never read viewport size. Rotating or resizing mid-round only rescales the board.
- If the selector’s eligibility is family-level only, add the smallest **generic**, manifest-declared variant-level eligibility, with no Mahjong-specific code in the selector. This is the one permitted exception to the zero-edit criterion; report it.

## Scoring

Formula shape is code inside the package’s own scoring file; values are admin-editable:

`score = pair × pairs + clear + floor(timeBonusMax × par / (par + activeSeconds))`

- `activeSeconds` is whole seconds from the server replay, minus only the server-owned entrance allowance. The client never submits score, time or variant.
- The time term decays smoothly and never goes flat, so slow clears are still ordered and do not tie at a floor. Integer arithmetic only.
- Three scoring configs, one per variant, each with its own live version, history, rollback, reason, expected-version check and audit. An edit changes future rounds and live-leaderboard eligibility for that variant only, and never changes saved scores, `completed_run` rows or admin counts. The admin page shows the three side by side and says so.
- Only a fully cleared board is ranked. A blocked board stays in history with pairs removed and time, with no leaderboard score.

## Ranked integrity

- Server replays every removal for legality against the issued seed and variant; tampered or illegal replays are rejected.
- **Timing floor:** manifest-owned minimum active time of pairs × 400 ms (starting value, tuned later from replay metrics). A ranked claim below the floor is downgraded to unranked following the existing superseded-session pattern. It is not a ban.
- **Hidden tab:** ranked time is server wall-clock, as in Memory. Before building, report what `visibilitychange` does to an active ranked round today. Acceptance: hide the tab for 20 seconds, return and finish, and the round counts as Finished, not Abandoned. Solo checkpoint and resume must work for Mahjong rounds.

## Faces and presentation

- 42 distinct original faces: 27 suit faces (three suits × 1–9), 4 winds, 3 dragons, 4 Flowers, 4 Seasons. Quick uses 14 plain faces chosen for legibility.
- Language-free and never colour-alone: suit identity by glyph and frame shape plus pattern; numbers 1–9 as pip grids with a small corner numeral (7, 8 and 9 must be countable at tile size); winds as arrow-like marks, not letters; dragons as three clearly different shapes.
- Flowers share one frame style and Seasons share another, so the group-match rule is visible. Help and the first-time tutorial show Flower to Flower and Season to Season.
- No copied art, no trademarked names. Do not use Shanghai or Mahjong Titans. Use a per-family theme profile in the manifest (palette size, symbol families and count, surfaces); the puzzle backdrop uses Mahjong tiles only.
- Motion as in the v1.3.4 proposal: layer-by-layer entrance with input locked until the logical deadline, pair removal about 180 ms, shared 420 ms result fade-rise, 500 ms score scramble only. Reduced motion settles immediately. No animation callback changes puzzle state.
