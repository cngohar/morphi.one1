## 3. Server Replay, Determinism, and Integrity

1. **Integer-Only Determinism:**
   - All deck layouts, warp shifts, hazard tiles, spectral categories, and reset pulses are calculated using the seed PRNG (`createRng(seed)`).
   - Zero client-only floating point RNG.
2. **Authoritative Cloudflare / D1 Replay:**
   - Server re-executes the move sequence against the seed.
   - For `life-support`: server tracks `power > 0` after every move.
   - For `sentinel-heat`: server confirms heat level and tile lock states.
   - For `glyph-chain`: server verifies matches occurred in ascending tier order.
3. **Loss State Handling (Ponytail / Cloudflare best practice):**
   - Rounds ending in loss (`life-support` depletion) do not save leaderboard entries or overwrite ranked personal bests.
   - The failed board displays a clear Retry / Return status without corrupted database state.
