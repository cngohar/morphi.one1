## Exact approved pilot (four legacy + six proposed additions)

| New ID / baseline            | Approved delta                                                                                                                                                                  | Counts / groups / scoring                                                                                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `memory:budget` / classic    | 2 completed attempts/group; final successful attempt wins; unsuccessful cap is a recoverable run-over with Home/Try another, no saved completion/score, exact-ID ranked abandon | 6/8/10 pairs; distinct `memory-1:budget:<groups>`; shared `brief-v1` pair scope                                                                               |
| `memory:lockout` / classic   | Last card flipped in a miss cannot be flipped on the following completed attempt; ignored taps spend nothing; no deadlock                                                       | 6/8/10 pairs; `memory-1:lockout:<groups>`; shared pair scope                                                                                                  |
| `memory:swaps` / classic     | After a mismatch hides, exactly two down unmatched cards swap deterministically; mark both positions until next accepted flip; <2 eligible makes no-op/no RNG                   | 6/8/10 pairs; `memory-1:swaps:<groups>`; shared pair scope                                                                                                    |
| `memory:two-backs` / classic | One dotted + one striped card per identical-symbol pair; same-back cards cannot match because pairs have opposite backs; accessible pattern/name, not color alone               | 6/8/10 pairs; `memory-1:two-backs:<groups>`; shared pair scope                                                                                                |
| `memory:quads` / trios       | Four identical symbols per attempt, 4/5/6 groups, six attempts/group, last attempt may win                                                                                      | 16/20/24 cards; `memory-1:quads:<groups>`; `memory-quads-v1` = 2000/quad −150/miss −5/whole second; separate immutable scoring scope, 0.8s/group ranked floor |
| `memory:collapse` / classic  | Matched cards leave and remaining cards compact in reading order; stable card identity, focus moves only to a surviving neighbor if needed                                      | 6/8/10 pairs; `memory-1:collapse:<groups>`; shared pair scope                                                                                                 |

Only meaningful rule deltas count; 10 total is a target, not an acceptance claim. ## Implementation reach and user risk

- **Owned Memory:** `src/lib/puzzles/memory/{logic,manifest,scoring,messages,Game,View,Card}.ts/.svelte` and README. Logic owns generation and all accepted flips; no cosmetic RNG for gameplay. After-miss swaps use the seeded logic stream with deterministic draw count. Match size, attempt budget, lock, stable collapse and opposite backs must replay from seed + accepted flips; no time or animation drives rules. `Game.svelte` owns visual indicators, accessibility, visible-time pauses and a loss state that survives refresh without becoming a completed score. Keep solo/ranked timing and accepted Card transitions for all four legacy variants.
- **Connected shared paths only if necessary:** `src/lib/ui/puzzle-view.ts` and `src/lib/screens/PlaySession.svelte` for budget no-save/Next + exact-ID ranked abandon and checkpoint recovery; `src/lib/engine/contract.ts` only for required manifest result contracts. `src/lib/server/{runs,ranked-session,games,scoring}.ts` and admin Games/Scoring/TestPlay only when new variant catalogue/scoring touches their existing generic flows. The client does not submit a score or pick a ranked seed. Never erase a previous result, overwrite D1 score history or silently mark a failed budget as won.
- **Generated projection/export:** update `scripts/generate-registry.ts` only if actual metadata contract needs changing; otherwise run the existing registry generator and include only its changed generated `src/lib/{catalog,registry,family-index,puzzle-metadata,puzzle-messages,scoring}.ts` outputs. `package.json`, Wrangler and migrations should remain unchanged unless actual source proves a necessity. No new public route.
- **Direct tests/fixtures:** Memory `logic.test.ts`/`variants.test.ts`, `tests/vectors/memory-{variants,runner,node,browser,worker}.*`, `tests/integration/memory-variants.test.ts`, `tests/e2e/memory-variants{,-admin}.spec.ts`, `tests/e2e/resume.spec.ts` where directly affected. Freeze `tests/vectors/reference.json` and existing known Memory vectors. Check `tests/integration/runs.test.ts`, selector/registry slices only when shared contracts change. Additional negative cases: cap final win vs loss, no-score/abandon, lock deadlock, swap pinned cards/zero eligible/RNG, patterned-back invariant, quad fit, collapse stable IDs/focus, malformed/unknown ids, stale/disabled issuance, checkpoint/retry, duplicate submit and score-version rollback.
