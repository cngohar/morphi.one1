### Implementation Summary

1. **10 Genuine Ruleset Mechanics (`src/lib/puzzles/memory/logic.ts`):**
   - **`memory:edge-cache` (CDN Edge Cache / Ghost Imprint):** When inspected cards mismatch, they leave an ephemeral ghost cache imprint on their card back for 2 subsequent turns before TTL expiration.
   - **`memory:quantum-entangle` (Quantum Entangled Twin Node):** Entangled twin card pair (⚛️) flips face-up simultaneously whenever either node is flipped.
   - **`memory:rate-limiter` (429 Rate Limiter / Cooldown Backoff):** Rapid mismatches increment rate limit counter; 3 consecutive mismatches trigger a 429 lockout cooldown.
   - **`memory:register-buffer` (Data Buffer Register):** Flipping the same revealed card twice stashes it into a 1-card buffer register in the HUD. Flipping its partner later matches directly with the buffer.
   - **`memory:firewall-ice` (ICE Firewall Barrier):** Central cells are encased in a firewall barrier (cannot be flipped) until any orthogonal adjacent neighbor is matched, breaching the shield.
   - **`memory:anycast-route` (Anycast Perimeter Re-Route):** Every 3rd mismatch triggers a network rebalance: remaining outer perimeter cards shift 1 step clockwise around the grid perimeter.
   - **`memory:tls-handshake` (3-Way TLS Handshake Triad):** Cryptographic protocol verification: cards feature Client Hello (`syn`) and Server Hello (`ack`) stages across matching cipher suites.
   - **`memory:trace-route` (Security Trace & Quarantine):** Mismatches increase active trace (+15%); reaching 100% trace places 2 random cards in encrypted quarantine for 3 turns. Matches cool trace (-10%).
   - **`memory:bit-rot` (Bit-Rot Data Transposition):** Seen unmatched cards suffer bit-rot data corruption after 3 turns and swap positions with an adjacent neighbor.
   - **`memory:burst-transmission` (Packet Burst Ping):** Chaining 2 consecutive matches triggers an uplink pulse illuminating 3 hidden cards for 0.8s.
