## Implementation and file inventory

- `src/lib/server/games.ts`:
  - Replaced per-variant SQL fan-out in `gameStatistics` with a single family-scoped grouped query:
    `SELECT rules_group, score_config_version, count(*) total, sum(CASE WHEN ranked=1 THEN 1 ELSE 0 END) ranked, sum(CASE WHEN hidden=1 THEN 1 ELSE 0 END) hidden, max(score) best, avg(score) average, avg(duration_ms) duration FROM completed_run WHERE family=? GROUP BY rules_group, score_config_version`
  - Reconciles historical variant aggregates in-memory against `variant.leaderboardGroups`, preserving exact cohorts, ties, and score-version attribution.
  - Reduces D1 statement counts from O(N) to O(1) (1 statement when family summary passed; 3 statements when standalone).
- `src/lib/server/games-admin.ts`:
  - Added `variantPage = 0, pageSize = 10` pagination arguments to `loadGamesAdmin`.
  - Computes `totalVariants`, `totalVariantPages`, and slices `pagedVariants` deterministically in manifest order.
  - Returns `{ ...stats, variants: pagedVariants, totalVariants, variantPage, variantPageSize: pageSize, totalVariantPages }`.
- `src/routes/admin/[view]/+page.server.ts`:
  - Extracts and sanitizes `variant_page` search parameter (`Math.max(0, Number(variantPageParam))`) and passes to `loadGamesAdmin`.
  - Lazily hydrates scoring version histories:
    `versions: subview === 'scoring' || event.params.view === 'scoring' ? await listScoreVersions(env.DB, family, variant) : []`
    Omits score-version list queries on Statistics and Settings tabs while retaining live config for test play.
- `src/lib/i18n/messages.ts`:
  - Added message keys: `admin.variants.pageNav`, `admin.variants.historyNav`, `admin.variants.detailHistoryNav`, `admin.variants.pageStatus`, `admin.variants.historyStatus`, `admin.variants.first`, `admin.variants.previous`, `admin.variants.next`, `admin.variants.last`, `admin.variants.emptyPage`, `admin.variants.returnFirst`.
- `src/lib/components/GamesAdmin.svelte`:
  - Added table pagination controls (`First`, `Previous`, `Next`, `Last`) with ARIA navigation landmarks and current page status.
  - Added empty-page state with return link when `variant_page` is out of range.
  - Added in-page pagination (10 rows per page) for family historical rules-group summary.
  - Added in-drawer pagination (10 rows per page) for variant inspection drawer history.
  - Preserved strict form allowlists by keeping action forms clean.
- `tests/integration/memory-variants.test.ts`:
  - Updated statement count assertion in existing test from 6 to 1 to match the grouped query optimization.
  - Added comprehensive integration test: `bounds Games queries, pages variants deterministically, and isolates scoring versions at synthetic 100-variant scale` asserting exact cohort preservation, page boundaries, out-of-range safety, statement count bounds, and version isolation.
