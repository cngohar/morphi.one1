### Implementation Summary
1. **Server Directory Pipeline (`src/lib/server/memory-directory.ts`):**
   - Keyset cursor pagination (`encodeCursor`, `decodeCursor`) with opaque base64 tokens (`cursor:<token>`) ensuring deterministic `(id ASC)` sorting without OFFSET query degradation.
   - Dual-source union: combines curated catalog variants (`catalog.memory.variants`) with observed uncataloged variants queried from `variant_lifecycle`, `play_session`, and `account_round_activity`.
   - Comprehensive multi-filter evaluator: supports slug/name substring match (`q`), status (`all`, `enabled`, `disabled`, `blocked`, `unplayed`), archetype (`core`, `information`, `grouping`, `dynamics`, `pressure`, `constraints`), and source (`curated`, `observed`).
   - Dimension breakdown resolver (`memoryVariantDimensions`) mapping each variant across the six finite Memory dimensions (`matchSize`, `opening`, `movement`, `backs`, `budget`, `availability`) against active policy values to determine blockers.
   - Telemetry aggregation via single grouped query and batch activity mapping (`queryActivityCounts`).
2. **Svelte 5 Directory UI Component (`src/lib/components/MemoryDirectory.svelte`):**
   - Responsive multi-filter search bar (`role="search"`), search input with reactive synchronization (`bind:value`), filter selects, and reset link.
   - Directory summary counter (`admin.directory.summary`, `admin.directory.curatedCount`).
   - Clean variant row cards displaying localized names, slug codes, source/status/archetype pills, compact dimension tag badges, telemetry metrics (`shown`, `played`, `playRate`), and inspect trigger.
   - Keyset pagination bar (`First`, `Previous`, `Next`, `Last`) with cursor token display.
   - Accessible inspection drawer modal (`dialog.drawer`): accessible title, dimension breakdown card grid with blocked highlights, telemetry breakdown, rules group identifier with direct link to scoring editor (`/admin/games?game=memory&subview=scoring#<group>`), backdrop click dismissal (`dismissOnBackdrop`), escape dismissal, and focus trap/restoration.
3. **Games Admin Integration & Route Wiring (`src/lib/components/GamesAdmin.svelte`, `src/routes/admin/[view]/+page.server.ts`):**
   - Added dedicated `Directory` tab to Memory section tabs (`/admin/games?game=memory&subview=directory`).
   - Loaded and passed `memoryDirectory` and `directoryFilter` to `<MemoryDirectory>` inside the admin card section.
   - Omitted the legacy unfilterable variants list when viewing the dedicated directory tab.
4. **Localization (`src/lib/i18n/messages.ts`):**
   - Added localized messages for directory title, filters, statuses, sources, dimensions header, scoring link, and empty states.
