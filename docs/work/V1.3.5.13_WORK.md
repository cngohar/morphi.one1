### Implementation Summary

1. **10 Genuine Ruleset Mechanics (`src/lib/puzzles/memory/logic.ts`):**
   - **`memory:workflows-step` (Durable Step Checkpointing):** Each match commits a durable step checkpoint (`workflowStep`). Mismatches roll back to the last checkpoint; cards discovered during failed branches flip back face-down.
   - **`memory:browser-rendering` (Headless Viewport Snapshot):** A headless crawler scans quadrants (`renderScanCountdown`). Every 3 flips, a viewport snapshot briefly illuminates a quadrant before fading back.
   - **`memory:ai-gateway` (Semantic Cache & 429 Cooldown):** Previously observed cards are cached (`cacheKnown`). Hitting rate limits (rapid consecutive mismatches) forces a cooldown backoff before flips resume.
   - **`memory:k2-streams` (Append-Only Event Cursor):** Flips and matches write to an append-only event log. Matching cards that align with the stream target produce an event burst (`streamBurst`), revealing the next stream entry.
   - **`memory:basin-catalog` (Iceberg Columnar Partition Pruning):** The board cards belong to columnar partitions (`partition`: `'A' | 'B' | 'C'`). Flipping a card activates its partition filter; cards in unselected partitions are temporarily pruned until the partition cycle completes.
   - **`memory:edge-snippets` (Header Injection Micro-Transforms):** Edge snippet micro-transforms inject synthetic headers (`activeHeader`) on each flip, altering card border aesthetics and granting reveal hints on header parity matches.
   - **`memory:images-transform` (Progressive Sharpness Layers):** Cards start with progressive blur layers (`blurLevel`: 2 -> 1 -> 0). Successful interactions and near-misses sharpen the image layers progressively until crisp focus is reached.
   - **`memory:waiting-room` (Concurrency Throttling & Admission):** An active queue throttling mechanism admits player flips based on queuing tokens (`waitingTokens`). Matching cards releases waiting room pressure and queues bonus admission tokens.
   - **`memory:privacy-pass` (Blind Cryptographic Token Probe):** Cryptographic privacy tokens (`privacyTokens`) allow zero-knowledge card probes without committing a full flip move, validating match equivalence with zero penalty.
   - **`memory:agents-sdk` (Autonomous Agent Tool Assist):** An AI agent loop (`agentCycles`) analyzes memory board entropy in the background; every 4 flips it invokes a tool call that highlights the highest-probability matching pair (`agentHint`).
