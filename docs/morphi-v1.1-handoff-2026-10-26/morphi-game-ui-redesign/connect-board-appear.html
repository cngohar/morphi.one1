How the Connect board APPEARS — the deal-in (Anime.js). Plays once, like a real deal — the board then stays arrived.
Total: exactly 2.5 seconds. 1 · Shell settles (first arrival only, 0–0.6s): the box rises and fades in, the bottom panel slides up, the scattered background fades in with it (it is never sitting there beforehand). 2 · The name arrives (0.3–0.85s): the puzzle name gets its own arrival beat — it rises, settles and fades in, in step with the board landing; the name arriving IS the reveal. 3 · The grid ripples in (0.5–1.25s): cells scale up in a ripple from the centre of the board outward, like a deal landing. 4 · Dots arrive in pairs (0.8–2.2s): both dots of a pair pop in together, pair after pair, and each pop sends out a soft ring in the pair’s own colour that expands and dissolves — before a single move, the player has already seen which two belong together. Then a short settle breath, the board is still, and play begins. On the next deal (Replay): the shell stays put — wordmark, account, box and bottom panel are static; only the new puzzle’s own things move: the name arrives again, the scatter re-fades, the board re-deals. Reduced-motion: everything is one plain fade.
